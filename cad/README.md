# SmoothSensors chassis CAD

3D modeled chassis for the robot, prepared with AutoCAD, exported to STL and ready to print in any Creality 3D printer.

## Files

* `RobotChassis03Split.dwg`: the main AutoCAD 3D model. It has 3 main layers, each with one part of the chassis: Top, Bottom and CasterSupport.
* `RobotChassis03Bottom.stl`: Bottom part of the chassis, exported to the STL format. This is the part where the battery and the motors are attached to the robot.
* `RobotChassis03CasterSupport.stl`: Caster wheel support part of the chassis, exported to the STL format.
* `RobotChassis03Top.stl`: Bottom part of the chassis, exported to the STL format. This is where all sensors, camera, USB Hub and the Arduino Uno Q will be attached.
* `RobotChassis03.3mf`: the Creality project for the chassis.
* `RobotChassis03Bottomt_PLA_3h21m.gcode`: the file to send to the 3D Printer for printing. It can be copied to a pen drive then insert the pen drive in the printer and print.
